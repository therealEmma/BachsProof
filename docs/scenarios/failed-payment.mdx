---
title: "Failed payment"
description: "Prevent fulfilment when a collection attempt failed."
---

## What problem does it test?

The collection attempt failed. A failed attempt must not be treated as a paid
order or wallet deposit. The customer must not receive a ₦5,000 credit merely
because a checkout or charge reference exists.

## What BachsProof sends

It creates a documented-shaped `collection.failed` event with `status:
"FAILED"` and the configured amount and currency. Delivery is sequential and
normally accepted by a handler that records the event without crediting. A
failed collection can leave a checkout open for another attempt; this fixture
does not model that retry.

```js
{
  name: "failed collection is not fulfilled",
  scenario: "failed-payment",
  amountMinor: 500_000,
  currency: "NGN"
}
```

## Expected result and failure

Zero credits are expected. A credit fails `INV-004`; a verifier is needed to
prove the ledger remains unchanged. The synthetic failed event is constructed
in `packages/bachs/src/fixtures.ts`, not received from a live provider.
