---
title: "CI/CD"
description: "Run BachsProof safely in automated tests."
---

Use a dedicated test application, database, queue, and webhook secret in CI.
Load the same `bachsproof.config.mjs` used locally, then run:

```bash
pnpm exec bachsproof test --json
```

The command exits non-zero when payment preparation, delivery, financial
verification, or an invariant fails. Store the JSON output as a CI artifact.
Never provide production credentials or production URLs to the job.
