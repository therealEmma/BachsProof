---
title: "Understanding test results"
description: "Read CLI summaries and separate delivery, verification, and invariant failures."
---

The CLI prints one line per configured scenario and a consolidated summary:

```text
PASS sequential duplicate webhook (financially verified; 24ms; 0 financial violations)
FAIL concurrent duplicate credit (financially verified; 31ms; 1 financial violations)
Summary: 1/2 passed, 1 failed, 2 financially verified, 0 unverified, 1 financial violations, 55ms
```

Investigate the failure by category:

| Symptom | Likely layer |
| --- | --- |
| Preparation failed | Test data or `createPayment` |
| Connection error / unexpected status | Target URL, route, server, or webhook handler |
| Expected 4xx did not occur | Signature, parser, or scenario expectation |
| Verifier timeout | Async worker, verifier query, or missing `pending` handling |
| `INV-001` | Duplicate financial effect or missing durable idempotency |
| `INV-002` / `INV-005` | Amount or currency matching |
| `INV-003` | Eligible payment was not credited |
| `INV-004` | Ineligible event created a credit |

Use `--json` when a CI job needs the full delivery and verification evidence.
