---
title: "Manual payment references"
description: "Run tests with references you prepared yourself."
---

Manual references are useful when another test already created the payment or
when your application has a fixture loader.

```js
export const tests = [
  {
    name: "known ₦5,000 payment is idempotent",
    scenario: "sequential-duplicate-webhook",
    reference: process.env.BACHSPROOF_REFERENCE,
    amountMinor: 500_000,
    currency: "NGN"
  },
  {
    name: "two known payments are independent",
    scenario: "concurrent-unique-payments",
    references: ["payment-a", "payment-b"],
    concurrency: 2,
    amountMinor: 500_000,
    currency: "NGN"
  }
];
```

Use one isolated reference per selected test. For the unique-payments scenario,
the array length must match `concurrency`, and references must be distinct.
BachsProof does not interpret positional environment variables as payment
identity. Explicit references take precedence over `createPayment`.
