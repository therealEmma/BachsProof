---
title: "Synthetic payment references"
description: "Use generated references only for isolated fixture tests."
---

Set `syntheticReferences: true` on a run, or use the generated environment
switch:

```powershell
$env:BACHSPROOF_USE_SYNTHETIC_REFERENCES = "true"
npx bachsproof test
```

Synthetic mode lets the provider adapter generate a local reference when no
application payment exists. It is useful for testing adapter serialization,
signature handling, or a fixture-only route. The `createPayment` callback is
not invoked in this mode.

It is not a real application payment. It cannot prove that your database found
the reference, that Bachs created a charge, that a customer paid ₦5,000, or
that a ledger was committed. Use real references and `verify` for financial
evidence. Never send synthetic events to production.
