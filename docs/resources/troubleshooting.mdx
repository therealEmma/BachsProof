---
title: "Troubleshooting"
description: "Fix common setup and financial verification failures."
---

## The config is rejected

Check that `webhookUrl` is a complete HTTP(S) URL, `secret` is non-empty,
`amountMinor` is a safe integer, and both callbacks are functions.

## Payment preparation failed

Check that `createPayment()` inserted a fresh isolated record and returned its
non-empty reference. BachsProof stops before sending a webhook when preparation
fails.

## Webhook delivery failed

Start the isolated application and check the full `webhookUrl`. Inspect the
application logs and confirm it accepts the generated signed Bachs envelope.

## Financial verification failed or timed out

Check that `verify(reference)` reads the requested record, returns the actual
currency and amount, and uses `pending: true` only while work is still running.
Do not return expected values when the record is missing.

## A negative scenario created a credit

Inspect the application eligibility check and the ledger rows. The report keeps
the observed count, amount, currency, and invariant identifier.
