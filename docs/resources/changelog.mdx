## 1.1.0

The four BachsProof packages are published publicly at version `1.1.0`:

- `@bachsproof/core`: provider-neutral runner, callback verification, five
  invariants, reports, replay metadata, and the HTTP race controller;
- `@bachsproof/bachs`: Bachs-shaped fixtures, 15 scenario plans, exact money
  helpers, parsing, normalization, and test signing;
- `@bachsproof/cli`: `bachsproof init`, `bachsproof test`, named suites, automatic
  payment preparation, JSON output, and config validation;
- `@bachsproof/sdk`: optional request-scoped checkpoint middleware and helpers.

The release also includes bounded asynchronous verification, the reference
wallet and PostgreSQL demonstration, independent package-installation tests,
and an explicit boundary between synthetic events and live provider claims.

This release does not add live Bachs checkout creation to BachsProof. Provider
sandbox validation, settlement, and production readiness remain outside the
mock adapter's evidence boundary.
