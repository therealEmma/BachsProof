## 1.1.0 development release

- Added the CLI onboarding workflow with `payproof init` and `payproof test`.
- Added automatic payment preparation through `createPayment`.
- Added callback financial verification and bounded asynchronous polling.
- Added 15 Bachs payment correctness scenarios.
- Added optional checkpoint-based controlled concurrency.
- Added the reference wallet and PostgreSQL correctness experiment.
- Simplified the public surface by removing target reset and HTTP inspection
  configuration.
- Added independent package-installation validation.

This repository has not published packages or executed live financial
transactions. Check the root repository for the release status and package
version actually available to your team.
