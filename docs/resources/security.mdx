---
title: "Security and safety"
description: "Keep BachsProof test-only."
---

- Use an isolated application, database, queue, and webhook secret.
- Create fresh test payment records before each scenario.
- Never use production URLs, keys, customer records, or payment references.
- Keep the secret in environment variables and out of source control.
- BachsProof sends local simulated events; it does not call Bachs or move money.
- BachsProof never deletes your application data automatically.

Webhook signing makes test requests authentic-looking. It does not make a
production system safe, and a passing run is not a production certification.
