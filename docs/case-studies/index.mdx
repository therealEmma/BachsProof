---
title: "Reference wallet case study"
description: "See BachsProof find and then verify a real duplicate-credit bug in a small test wallet."
---

BachsProof's reference wallet is the main engineering demonstration in this
documentation. It is a small test application with two versions of the same
webhook handler:

- the vulnerable version can credit one payment twice when two requests overlap;
- the corrected version uses the store's protection and credits it once. The
  in-memory test uses a synchronous critical section; the PostgreSQL test uses
  a transaction and a unique idempotency key.

The experiment uses local synthetic events and an isolated test store. It does
not represent a live Bachs payment or prove that another application is safe.
