---
title: "Scenario run options"
description: "Reference for RunOptions and expected HTTP outcomes."
---

| Field | Type | Required | Meaning |
| --- | --- | --- | --- |
| `scenario` | `ScenarioName` | Yes | One of the 15 implemented names |
| `amountMinor` | `number` | No | Test amount; Bachs fixture default is 5,000,000 |
| `currency` | `string` | No | ISO-style currency; Bachs fixture default is `NGN` |
| `reference` | `string` | For one-payment real runs unless prepared | Application payment reference |
| `references` | `string[]` | For unique-payment manual runs | Distinct references, one per participant |
| `concurrency` | `number` | No | Positive participant count; scenario default is 2 where applicable |
| `syntheticReferences` | `boolean` | No | Explicitly opt into generated local references |
| `expectedStatus` | `number`, `number[]`, `"2xx"`, `"4xx"`, `"5xx"` | No | Accepted HTTP result for scenario deliveries |
| `delayMs` | `number` | No | Provider-plan delay for delayed confirmation |
| `seed` | `string` | No | Replay/debug metadata |

`concurrent-unique-payments` accepts `references`, not `reference`. All other
scenarios accept one `reference`, not `references`.
