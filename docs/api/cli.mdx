## `bachsproof init`

```text
bachsproof init [directory] [--force]
```

| Argument | Default | Meaning |
| --- | --- | --- |
| `directory` | Current working directory | Independent project to initialize |
| `--force` | Off | Replace generated files that already exist |

The command creates `bachsproof.config.mjs`,
`tests/bachsproof.test.mjs`, `tests/bachsproof.setup.mjs`, and
`tests/bachsproof.verify.mjs`. Without `--force`, it refuses to overwrite any of
them.

## `bachsproof test`

```text
bachsproof test [--config <path>] [--name <test-name>] [--json]
```

| Flag | Default | Meaning |
| --- | --- | --- |
| `--config` | `bachsproof.config.mjs` | Config module to load |
| `--name` | All configured tests | Run one exact `name` |
| `--json` | Human-readable output | Print JSON results for CI |

The process exits `0` when all selected results pass and `1` when a selected
result fails or configuration cannot be loaded. The CLI runs configured tests
sequentially; a scenario can still contain concurrent deliveries. `--json`
includes the reports and redacts the configured signing secret from output.
