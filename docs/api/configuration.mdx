---
title: "CLI configuration"
description: "Reference for BachsProofConfig and its defaults."
---

| Field | Type | Required | Default / behavior |
| --- | --- | --- | --- |
| `provider` | `ProviderAdapter` | Yes | No default |
| `target.baseUrl` | `string` | Yes | Base URL for the application |
| `target.webhookPath` | `string` | Yes | Path appended with `new URL` |
| `target.headers` | `Record<string,string>` | No | Added to every delivery |
| `tests` | `BachsProofCliTest[]` | Yes, non-empty | Selected sequentially by the CLI |
| `createPayment` | `PaymentReferenceCreator` | No | Called only when a reference is missing |
| `verify` | `FinancialVerifier` | No | No committed-state observation when absent |
| `financialVerification` | `FinancialVerificationOptions` | No | 10,000ms completion, 25ms polling, 250ms negative window |
| `checkpoint.name` | `string` | No | Controlled mode disabled |
| `checkpoint.timeoutMs` | `number` | No | 10,000ms controller wait |
| `signing.type` | `"bachs"` | No | No CLI signing wrapper |
| `signing.secret` | `string` | With Bachs signing | Must be non-empty |
| `signing.timestamp` | `number` | No | Current Unix timestamp when omitted |
| `requireFinancialVerification` | `boolean` | No | `false`; fails config loading when true and `verify` is absent |

```js
import { defineConfig, bachsAdapter } from "@bachsproof/cli";
import { tests } from "./tests/bachsproof.test.mjs";

export default defineConfig({
  provider: bachsAdapter({ mode: "mock" }),
  target: {
    baseUrl: "http://127.0.0.1:3000",
    webhookPath: "/webhooks/bachs"
  },
  tests,
  requireFinancialVerification: true
});
```

`defineConfig` returns the same object; it exists to preserve TypeScript
inference and editor feedback. Config loading is implemented in
`packages/cli/src/runner.ts`.
