This reference is checked against the exported TypeScript in the four published
`1.1.0` packages. The CLI is the easiest public surface; the core, Bachs, and
checkpoint pages explain the lower-level contracts.

  <Card title="Adapters" href="/api/adapters" icon="plug">Provider extension contracts.</Card>
  <Card title="Reports" href="/api/reports" icon="file-json">Structured evidence fields.</Card>

Payment preparation, verification, and cleanup belong to the application's test
environment. Reset endpoints and HTTP inspection configuration are intentionally
not part of this API.
