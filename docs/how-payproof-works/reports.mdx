---
title: "Test reports"
description: "Read the structured evidence PayProof records for every run."
---

Each run returns a `PayProofResult` containing `passed` and a structured
`PayProofReport`. The report is designed for debugging and replay, not only for
a green/red status.

It includes:

- scenario, provider, and provider mode;
- primary payment reference and expected state;
- observed state and invariant violations when verification ran;
- whether financial verification was used;
- every delivery and its HTTP result;
- checkpoint trace events;
- errors and timestamps;
- replay seed, concurrency, checkpoint name, and controlled flag.

The CLI prints a compact summary and supports `--json` for CI artifacts. Use
`writeReport` from `@payproof/core` when a programmatic test needs a durable
JSON file.
