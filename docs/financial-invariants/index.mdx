---
title: "Financial invariants"
description: "The five rules BachsProof checks against committed records."
---

BachsProof checks saved financial state, not only HTTP status.

1. `INV-001` — one payment must not create multiple credits.
2. `INV-002` — a credit must have the expected amount and currency.
3. `INV-003` — an eligible successful payment must create the required credit.
4. `INV-004` — an ineligible payment must not create a credit.
5. `INV-005` — the total financial result must equal the expected amount.

The report includes the invariant identifier, a plain-language reason, and the
observed financial evidence.
