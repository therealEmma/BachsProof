---
title: "Installation"
description: "Install the single supported BachsProof package."
---

Install the CLI as a development dependency:

```bash
pnpm add -D @bachsproof/cli
```

The CLI installs the core runner and Bachs adapter automatically. You do not
need to install another BachsProof package or modify your application to use an
SDK.

Use Node.js 22 or later. Run the initializer from the root of the isolated
application:

```bash
pnpm exec bachsproof init
```

This creates only `bachsproof.config.mjs`. It refuses to overwrite an existing
file unless you pass `--force`.

If you have not built the Bachs payment flow yet, start with the official
[development environment guide](https://docs.bachs.io/get-started/development-environment)
and [Checkout guide](https://docs.bachs.io/guides/checkout/checkout-sessions).
BachsProof begins after your application has a payment record and a webhook
route to test.
