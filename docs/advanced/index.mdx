title: "Advanced testing"
description: "Use the programmatic runner, framework integrations, checkpoints, and custom adapters."
---

The CLI is the easiest entry point, but PayProof also exposes a programmatic
runner for an application's existing test framework.

<CardGroup cols={2}>
  <Card title="Programmatic API" href="/advanced/programmatic-api" icon="code">
    Create a runner directly and assert on `PayProofResult`.
  </Card>
  <Card title="Controlled concurrency" href="/advanced/controlled-concurrency" icon="split">
    Coordinate an application barrier when ordinary HTTP overlap is not enough.
  </Card>
  <Card title="Checkpoint SDK" href="/advanced/checkpoint-sdk" icon="pause">
    Add optional, test-only instrumentation without coupling production flow.
  </Card>
  <Card title="Custom adapters" href="/advanced/custom-adapters" icon="plug">
    Bring another documented provider contract to the provider-neutral core.
  </Card>
</CardGroup>

The advanced API is optional. The default remains black-box HTTP testing with no
application source changes.
